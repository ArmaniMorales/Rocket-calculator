# Rocket Stability & Physics Calculator

A standalone aerospace physics application built to evaluate model rocket stability margins prior to launch. 

## Features
- **Center of Pressure (CP):** Calculates the exact aerodynamic CP using the **Barrowman Equations** to analyze nose cone and fin forces.
- **Center of Gravity (CG):** Computes the physical balancing pivot point based on component mass distribution.
- **Static Margin Evaluation:** Calculates the distance between CP and CG in calibers to flag unsafe, optimal, or over-stable rocket profiles.
